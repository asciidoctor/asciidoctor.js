= README

[.path]_cli.d.ts_ is generated from [.path]_lib/cli.js_ (`npm run build:types`) and is committed.

The other TypeScript Declaration Files are generated by `@asciidoctor/core`.
They are copied from [.path]_packages/core/types_ when a release is performed (see [.path]_tasks/publish.js_) and when the types are tested (`npm run test:types`, see [.path]_tasks/copy-types.js_).
These copied files are ignored by Git.

NOTE: The copy does not regenerate the types.
After changing the JSDoc in `@asciidoctor/core`, run `npm run build:types -w @asciidoctor/core` before `npm run test:types`, otherwise the test runs against outdated declarations.
